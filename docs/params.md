# Run parameters

Source: `docs/params.sql`. Set any param with `--<param> <value>`.

|   group   |        param         |                              default                               |           modes           |                                                                     description                                                                     |
|-----------|----------------------|--------------------------------------------------------------------|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| core      | `mode`               | `standard`                                                         | all                       | qc \| standard \| tag3p \| slamseq \| download                                                                                                      |
| core      | `input`              | `null (required)`                                                  | all                       | samplesheet.csv; for download, a text file with one query per line                                                                                  |
| core      | `outdir`             | `results`                                                          | all                       | publish root; each process writes &lt;outdir&gt;/&lt;process_name&gt;/                                                                              |
| reference | `genomes`            | `null`                                                             | standard tag3p slamseq    | CSV name,fasta,gtf[,star_index,rsem_index,gedi_index]; samplesheet genome column picks one per sample; outputs go to &lt;outdir&gt;/&lt;genome&gt;/ |
| reference | `fasta`              | `null`                                                             | standard tag3p slamseq    | genome FASTA (uncompressed) when --genomes is not used                                                                                              |
| reference | `gtf`                | `null`                                                             | qc standard tag3p slamseq | annotation GTF when --genomes is not used; optional in qc                                                                                           |
| reference | `star_index`         | `null`                                                             | standard tag3p slamseq    | prebuilt STAR index dir; skips STAR_GENOMEGENERATE (per genome: star_index column)                                                                  |
| reference | `rsem_index`         | `null`                                                             | standard                  | prebuilt RSEM ref dir with genome.transcripts.fa; skips RSEM_PREPAREREFERENCE                                                                       |
| reference | `gedi_index`         | `null`                                                             | slamseq                   | prebuilt GEDI index dir with one &lt;name&gt;.oml; skips GEDI_INDEXGENOME                                                                           |
| library   | `strandedness`       | `null`                                                             | standard tag3p slamseq    | unstranded \| forward \| reverse; null = forward for tag3p, else unstranded; samplesheet column overrides                                           |
| quant     | `quantifiers`        | `salmon,rsem,featurecounts`                                        | standard slamseq          | comma list; tag3p always featureCounts only, slamseq only reads featurecounts                                                                       |
| quant     | `isoform`            | `null`                                                             | standard                  | comma list of stringtie, ballgown, cufflinks; null = skip                                                                                           |
| quant     | `count_introns`      | `true`                                                             | standard tag3p slamseq    | derive introns.saf from the GTF and count reads in introns                                                                                          |
| quant     | `gene_count_args`    | `-t exon -g gene_id`                                               | standard tag3p slamseq    | featureCounts feature/attribute flags for gene counts                                                                                               |
| quant     | `intron_count_args`  | ""                                                                 | standard tag3p slamseq    | extra featureCounts flags for intron counts                                                                                                         |
| quant     | `regions`            | `null`                                                             | standard tag3p slamseq    | CSV name,file,feature,attribute,args[,genome]; BED/SAF/GTF regions for featureCounts; empty genome = all genomes                                    |
| qc        | `contaminants`       | `null`                                                             | standard tag3p slamseq    | CSV name,fasta,bowtie2_index; FastQ Screen genome panel                                                                                             |
| qc        | `skip_rustqc`        | `false`                                                            | standard tag3p            | skip RustQC on aligned BAMs                                                                                                                         |
| slamseq   | `no4su_pattern`      | `null`                                                             | slamseq                   | regex for unlabeled sample names; null = GEDI default no4sU\|nos4U                                                                                  |
| slamseq   | `slam_prefix`        | `slam`                                                             | slamseq                   | GRAND-SLAM output prefix (gedi_slam/slam/&lt;prefix&gt;.*)                                                                                          |
| download  | `download_source`    | `auto`                                                             | download                  | auto = ENA fastq then SRA fallback; ena \| sra = force one                                                                                          |
| download  | `download_max_reads` | `null`                                                             | download                  | cap reads per file for test pulls; capped files skip md5                                                                                            |
| download  | `download_max_runs`  | `null`                                                             | download                  | cap runs per query                                                                                                                                  |
| download  | `zenodo_pattern`     | `\.(fastq\|fq)\.gz$`                                               | download                  | regex for which Zenodo record files to fetch                                                                                                        |
| download  | `zenodo_mate_regex`  | `^(.+?)[._-]R?([12])(_001)?\.(fastq\|fq)\.gz$`                     | download                  | regex: group 1 = sample, group 2 = mate; non-matching files are single-end                                                                          |
| tool args | `star_args`          | `map per mode`                                                     | standard tag3p slamseq    | STAR_ALIGN flags by mode (see nextflow.config)                                                                                                      |
| tool args | `star_preset`        | `default`                                                          | standard                  | default = star_args.standard (nf-core style); encode_standard = star_encode_args (ENCODE3 flags RSEM uses with --star)                              |
| tool args | `star_encode_args`   | `ENCODE3 flag string`                                              | standard                  | STAR_ALIGN flags used when --star_preset encode_standard (see nextflow.config)                                                                      |
| tool args | `fastp_args`         | `map per mode`                                                     | all except download       | FASTP flags by mode; qc disables trimming                                                                                                           |
| tool args | `featurecounts_args` | `map per mode`                                                     | standard tag3p slamseq    | extra featureCounts flags by mode (tag3p: -M --fraction)                                                                                            |
| tool args | `gedi_slam_args`     | `-full -progress -D -trim5p 20 -trim3p 20 -snpConv 0.05 -modelall` | slamseq                   | GRAND-SLAM flags                                                                                                                                    |
